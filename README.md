# Архитектура ПО спринт 1

## Задача
Разделить проект Mesto на микрофронтенды.
Судя по файлу package.json, в котором указаны зависимости React (react, react-dom):
    "react": "^17.0.2",
    "react-dom": "^17.0.2",
Можно отсавновитб выбор на Module Federation, который подходит для React.

## Используемые технологии
- Module Federation
- React
- Webpack 5

## Структура
Микрофронтенды  
| Название       | Функционал                     | Порт  |  
|----------------|--------------------------------|-------|  
| host           | Основное приложение, главн стр | 3000  |  
| auth-mf        | Авторизация                    | 3001  |  
| profile-mf     | Редактирование профиля         | 3002  |  
| cards-mf       | Лента карточек, удаление фото  | 3003  |  
| likes-mf       | Учёт лайков                    | 3004  |  
| modal-mf       | Попапы                         | 3005  |
